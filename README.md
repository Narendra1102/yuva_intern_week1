# Week 1 – Responsive Landing Page

## Project
Nexa is a creative interpretation of a standard landing-page wireframe. It contains a sticky header, responsive navigation, hero section, feature highlights, process section, CTA and footer.

## Technologies
- Semantic HTML5
- Modern CSS3 with Grid/Flexbox and media queries
- Vanilla JavaScript

## How to run
Open `index.html` directly in a browser. No build tools or dependencies are required.

## Responsive testing
Test at desktop, tablet and mobile widths using browser DevTools. The navigation changes to a mobile menu below 800px.
